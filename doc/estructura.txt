## 🧩 Descripción de Componentes

### `main.py`
- Archivo principal de la app Streamlit
- Controla la navegación, interfaz, formularios, edición, filtros, eliminación, exportación y recordatorios
- Ahora incluye módulo **Gestión de Mensajes WhatsApp**

---

### `db/cotizaciones.db`
- Base de datos SQLite local
- Contiene las tablas:
  - `cotizaciones`: con campos como `telefono`, `auto`, `link_auto`, `whatsapp_link`
  - `mensajes_whatsapp`: con mensajes predeterminados personalizables para usar en WhatsApp

---

### `export/`
- Carpeta para guardar archivos exportados por el usuario
- Por ejemplo: cotizaciones en Excel (`.xlsx`)

---

### `utils/db_utils.py`
- Módulo con funciones auxiliares para la base de datos:
  - Conexión a SQLite
  - Crear tablas
  - Insertar, actualizar, eliminar cotizaciones
  - CRUD para mensajes de WhatsApp
  - Alter dinámico para agregar campos (`link_auto`)

---

### `utils/seed_mensajes.py`
- Script auxiliar para insertar mensajes predefinidos
- Usado para cargar plantillas en la tabla `mensajes_whatsapp`

---

### `doc/README_COTIZACIONES.md`
- Documentación técnica y funcional del sistema
- Explica módulos, funciones, tecnologías y estructura del proyecto

---

### `doc/estructura.txt`
- Este archivo
- Resume la estructura del proyecto en forma explicativa

---

### `requirements.txt`
- Lista de dependencias Python necesarias para ejecutar la app
